# Highway Lot

A nationwide car marketplace demo (listings, boosted/featured ads, dealer
subscriptions, a "find my car" quiz, and an ad-targeting data dashboard).

## Run it locally
npm install
npm run dev

## Deploy
Push this repo to GitHub, then import it in Vercel (https://vercel.com/new).
Vercel auto-detects Vite and deploys it — no config needed.
